STL File *RECOMMENDED IF YOU ARE USING AN OLDER SLICER* (This does not have the slicer settings implemented): [v22.stl](https://drive.google.com/file/d/1MunQBmEyD2P9_4tJkWeEvz2LHerrbMSM/view?usp=sharing)

This print was made with PLA filament. It was not tested on any other filament types. Experiment with other filaments at your own risk.

The glider is very brittle. Try not to throw it in a position where it will land on concrete. 

Throw the plane straight (at a 0° angle) with a moderate amount of force. It is best used when thrown from high areas where it will glide a long way before landing.

1. Import the 3D file type you chose to use (.3mf or .stl).
2. If you chose .3mf, you can slice the model and print right away. The .3mf already includes the nose modifier.
3. If you chose .stl, you will need to right-click the model in the slicer and click ‘Add Modifier.’ Select the cube modifier.
4. After the modifier is added, drag it to the nose of the plane and scale it so that it covers the front of the nose up to the front of the wings.
5. In the modifier settings set infill to 100% so that the nose is heavier than the rest of the glider. 
6. In the settings for the rest of the plane (the other object on the build plate), set infill to 0%, wall loops to 2, and enable supports. Any type of support will work. I’ve found normal supports to be the easiest and tree supports harder to remove.
7. These are all the settings you need to change, you are now ready to slice and print the model.
